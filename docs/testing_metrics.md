# Метрики тестирования

| Метрика | Значение / способ получения |
|---|---|
| Покрытие инструкций | Цель ≥ 80%; фактическое значение взять из отчёта JaCoCo |
| Количество тестов | Определяется выводом Maven Surefire |
| Плотность дефектов | Число подтверждённых дефектов / KLOC; заполнить после инспекции |
| Среднее время обнаружения | Сумма интервалов от старта теста до обнаружения дефекта / число дефектов |

Не подставлять предполагаемые числа как фактические. Отчёт JaCoCo формируется в `target/site/jacoco/`.
