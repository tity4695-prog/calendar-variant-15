# Инспекция кода

Проверяемые аспекты: понятные имена, единый стиль, инкапсуляция, обработка null, отсутствие изменяемого наружного состояния, корректность временных сравнений.

Команды:
- `mvn clean verify` — тесты и проверка JaCoCo;
- `mvn -q -DskipTests package` — проверка сборки.

Результаты инспекции необходимо подтвердить запуском команд в своей среде. В частности, проверить, что список событий возвращается как неизменяемая копия, а пересечение интервалов рассчитывается по полуоткрытой логике `[start, end)`.
