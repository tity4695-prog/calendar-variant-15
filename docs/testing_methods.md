# Сравнительный анализ методов тестирования

**Анализ граничных значений.** Эффективен для дат, времени, длительности и числовых ограничений; позволяет находить ошибки на переходе между допустимыми и недопустимыми значениями. Не гарантирует проверку всех внутренних ветвей.

**Эквивалентное разбиение.** Делит входы на классы, внутри которых ожидается одинаковое поведение; уменьшает число тестов. Может пропустить дефекты на границах классов.

**Покрытие решений и условий.** Проверяет истинные и ложные исходы логических решений и отдельных условий. Полезно для ветвлений, но само по себе не доказывает корректность требований.

Для календаря граничные значения особенно полезны, поскольку ошибки часто связаны с равенством начала и окончания, високосными датами, длительностью и пересечением интервалов.
